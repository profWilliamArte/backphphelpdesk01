🛠️ API Helpdesk - Documentación para Alumnos

Backend en PHP puro + MySQL. Inicia el servidor con:

php -S localhost:8000

🔐 Autenticación

POST /api/auth.php
Iniciar sesión. 
{
  "email": "admin@helpdesk.com",
  "password": "password"
}

🎫 Tickets

GET /api/tickets.php?user_id=user-001
Listar tickets del usuario (admin ve todos).
POST /api/tickets.php
Crear un nuevo ticket. 
{
  "title": "Error al imprimir",
  "description": "La impresora no responde",
  "created_by": "user-003",
  "category_id": "cat-003",
  "priority": "high"
}
GET /api/tickets.php?id=ticket-001
Obtener detalle de un ticket.
PUT /api/tickets.php?id=ticket-001
Actualizar un ticket. 
{
  "status": "in_progress",
  "assigned_to": "user-002"
}

💬 Comentarios

POST /api/comments.php
Agregar comentario a un ticket. 
{
  "ticket_id": "ticket-001",
  "user_id": "user-002",
  "content": "Revisando el problema...",
  "is_internal": true
}
GET /api/comments.php?ticket_id=ticket-001
Listar comentarios de un ticket.

🧪 Datos de prueba

Usuarios:
• Admin: user-001 | email: admin@helpdesk.com
• Agente: user-002 | email: agente@helpdesk.com
• Usuario: user-003 | email: usuario@helpdesk.com
